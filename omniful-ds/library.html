Foundations

Color

The palette is deliberately quiet. One vibrant primary carries every interactive affordance; greys do the structure; six accent hues are reserved exclusively for status. The rule an operator learns once: if it's blue you can click it, if it's colored it's a status.

Why one blue: ops screens are 90% table. A single interactive hue keeps 50-column screens scannable — anything colored is guaranteed to be information, not decoration.
Foundations

Typography

One family — Poppins — with a strict rule: line-height = font-size × 1.5. Vertical rhythm is automatic on every screen, with no per-style eyeballing. Body is 14/21 because operators read thousands of rows a day.

Spacing & radius

A 12-step scale with a deliberately tight low end — dense tables need 2px and 4px steps an 8-point grid can't give. Radii pair with component size so corner curvature always looks proportional.

Elevation

Three shadow levels only. Cards sit nearly flat, popovers float, modals dominate — depth maps to how much attention something demands.

Icons

230 custom glyphs drawn for the domain — Hub, Picking Wave, Manifest, Return Gate Entry — because generic icon packs don't speak warehouse. Single-color currentColor strokes on a 16×16 grid, so any icon inherits any text color.
